# Сайт ↔ бот и сборщик статистики: предложение для согласования

Статус на 28.11.2026: **предложение, не согласовано**. Код бота из этой задачи не изменялся и не читался.

## 1. Новые страницы в сборщике `/event` (нужно в первую очередь)
Сайт отправляет те же события и поля: `{event, page, source}`. Добавились значения `page`:

- `/perenos-bota-v-max/`
- `/bot-dlya-salona-krasoty/`
- `/bot-dlya-avtoservisa/`

Если сборщик проверяет `page` по списку, добавить их. Пока этого нет, события с новых страниц могут отклоняться и не учитываться.

`event`: `page_view`, `telegram_click`, `brief_copy` — без изменений.
`source`: `direct`, `google`, `yandex`, `bing`, `social`, `other` — без изменений.
Что изменилось в определении источника: он сохраняется в `sessionStorage` вкладки при внутренних переходах; учитывается `utm_source`, сведённый к тем же категориям.
`brief_copy` теперь возникает и при кнопке «Скопировать и открыть Telegram».

## 2. start-параметры
Сейчас (`legacy`): `?start=site`.
Предложение (`v1`): `?start=site_<источник>_<страница>`, например `site_ya_max`.

| Источник | Код |
|---|---|
| direct | dir |
| google | gg |
| yandex | ya |
| bing | bg |
| social | soc |
| other | oth |

Коды страниц: `home`, `tg`, `max`, `vk`, `wa`, `ai`, `zapis`, `zayavki`, `perenos`, `salon`, `avto`, `privacy`, `other`.

Проверка на стороне бота (строгий список, всё прочее — обычный `/start`):

```
^(site|site_(dir|gg|ya|bg|soc|oth)_(home|tg|max|vk|wa|ai|zapis|zayavki|perenos|salon|avto|privacy|other))$
```

Требования:
- старое значение `site` должно продолжать работать (кэш и сайт без JavaScript);
- параметр приходит от пользователя и может быть подделан: только для статистики, без прав и скидок;
- источник и страница, связанные с Telegram ID, — это новые сведения об обращении. До включения дополнить политику конфиденциальности (сейчас там отметка перехода со сроком до 30 дней).

## 3. Порядок включения
1. Бот принимает оба формата и проверен тестовыми переходами.
2. Владелец согласует текст политики.
3. Сборка с `SITE_START_PARAMS=v1`. Если Tuqo не поддерживает переменные сборки, изменить значение по умолчанию в `landing/build.mjs` и обновить тест на `legacy`.
4. Откат: вернуть `legacy`.
