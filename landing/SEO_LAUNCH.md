# SEO / AI Search — чеклист запуска

1. Получить реальный адрес сайта. Указать его в `SITE_URL` или `landing/site-url.txt`. Пересобрать и проверить canonical, sitemap, robots.
2. Проверить HTTP `200`, отсутствие `noindex` на коммерческих страницах, `https`, мобильную адаптивность, доступность страниц без JavaScript.
3. Подключить Яндекс Вебмастер, Google Search Console, Bing Webmaster Tools. Верифицировать владение, отправить `/sitemap.xml`.
4. При изменениях направлять `IndexNow` уведомления Яндексу и Bing (только после получения домена и размещения ключа).
5. Проверить SearchBot/Googlebot/Yandex/Bingbot в логах/тестах; отсутствие блокировок на уровне WAF/хостинга. robots — необходимое, но недостаточное условие индексации.
6. Создать честные практические статьи/кейсы, когда появятся реальные результаты, размещать ссылки с Авито и профилей бизнеса; фейковые отзывы/кейсы запрещены.
7. Установить Яндекс Метрику только после отдельного решения по cookies/персональным данным и нужным уведомлениям.
8. `llms.txt` — необязательная подсказка некоторым ИИ-агентам, не официальный механизм гарантированного попадания в ответы ChatGPT/Google.
9. Явное разрешение OAI-SearchBot открывает доступ ChatGPT Search; `GPTBot` отдельно отвечает за обучение, можно разрешить или ограничить независимо.
10. Проверить релиз на телефоне, скорость загрузки, отправку Telegram-заявок, ограничения API платформ.
