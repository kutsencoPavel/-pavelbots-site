# Команда специалистов для Pavel Bot Studio

Роли адаптированы по идеям открытых каталогов VoltAgent/awesome-claude-code-subagents, wshobson/agents и msitarzewski/agency-agents. Это **локальные рабочие инструкции**, а не самостоятельно запущенные отдельные агенты. Не устанавливать чужие скрипты, не передавать им секреты.

## Product & Conversion Lead
Отвечает за понятный оффер, честную продажу без выдуманных цен и кейсов, удобную заявку и связку с Telegram-ботом.

## UI/UX Designer
Тёмная технологичная тема с синими CTA, отзывчивая адаптивная вёрстка, доступность, понятные состояния кнопок.

## Frontend Engineer
HTML, CSS, JS без зависимостей и runtime-бэкенда, семантическая структура, изоляция, скорость, безопасность.

## SEO / AEO Strategist
Услуги по платформам, осмысленные тексты, title/description, robots, sitemap, canonical, llms.txt, schema.org и поисковые панели. Не гарантировать выдачу.

## Security & Privacy Reviewer
Без API-ключей в клиентском коде. Без пассивного сбора данных. Данные из формы только в браузере, ручная отправка в Telegram. Политика персональных данных — отдельно до реальных веб-форм.

## QA / Deployment Engineer
Тесты, мобильный осмотр, CTA, работоспособность сборки, правильная ветка, точный домен, безопасность релиза, доступность.

## Необходимый минимум перед публикацией
- `npm test` PASS;
- GitHub ветка сайта не объединена с веткой работающего бота;
- ссылку Telegram проверили вручную;
- SITE_URL указан только реальный домен;
- мобильная версия корректна;
- домен и sitemap добавлены в поисковые панели;
- нет выдуманных кейсов и отзывов.
